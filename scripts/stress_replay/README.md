# Reconstructed stress replay

`CMDO_SYSTEM_STRESS_AUC_V1_1_DENSELAMBDA_RECONSTRUCTED.py` reconstructs the
controlled AUC stress-test design for diagnostic replay.

It is deliberately separated from the manuscript Figure 5 source.

The final manuscript Figure 5 uses the frozen tracked CSV under
`source_data/figure5_submission/`. The reconstructed replay must never overwrite it.
