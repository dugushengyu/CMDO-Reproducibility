# Results v1 — finite-sample certifiable reuse

Date: 2026-09-07

Status: exploratory branch only; frozen manuscript unchanged.

## What has been established mathematically

### 1. Magnitude-only impossibility under same-audit adaptation

A general bounded construction now proves: for every `0<omega<1`, one can choose an unbiased bounded direct estimator and bounded historical value such that **every fixed borrowing weight in `[0,omega]` is MSE non-inferior**, while a data-dependent same-audit rule whose weight never exceeds `omega` is strictly harmful.

This upgrades the earlier single numerical counterexample into a general theorem. The implication is stronger than 'large weights can hurt': no non-zero pointwise cap on weight magnitude is, by itself, a universal same-audit safety device.

### 2. Honest role separation restores a finite-sample certificate

If the borrowing decision is based on an independent current decision audit, an exact finite-sample confidence set for current performance can be converted into an observable worst-case mismatch coordinate `Lambda_U`. On the confidence event, any fixed conditional weight below `2/(1+Lambda_U)` is MSE non-inferior to the evaluation-only direct estimator.

This gives a high-probability conditional risk certificate without target-truth leakage.

### 3. Full-budget direct evaluation creates a certifiability boundary

When role separation spends part of the current-outcome budget, comparison against full-budget direct evaluation is possible only if

`delta <= 1/(1+Lambda_U)`,

where `delta` is the variance penalty induced by withholding outcomes from the evaluation estimator. If this inequality fails, **no borrowing weight exists** that can be certified against the full-budget direct benchmark under the stated worst-case mismatch bound.

This is a feasibility boundary rather than a tuning formula.

## What the frozen U10 summaries already show

The earlier oracle diagnostic remains strong:

- all 8/8 observed shared-adaptive mean weights are below the oracle role-separated cap;
- all 8/8 matched constant-mean-weight rules are beneficial;
- 5/8 shared-adaptive states are nevertheless harmful relative to full direct evaluation.

Thus the magnitude-only limitation is not merely a synthetic corner case; U10 exhibits precisely the empirical pattern that motivates an explicit dependence term.

## New negative result: the simplest non-oracle full-budget certificate is operationally vacuous at U10-like settings

A separate exact enumeration was performed for an **iid binomial decision/evaluation design** using the frozen U10 target accuracies, historical accuracy, and total budgets only as parameter settings. For each of the eight cohort-budget states, decision fractions from 0.05 to 0.80 were examined using a 95% exact Clopper-Pearson decision-audit confidence interval.

Result: the simple Theorem-3 full-budget certificate had **zero trigger probability in all eight U10-like states across the examined split fractions**.

This does not invalidate Theorem 3. It shows that the naive recipe

`exact confidence set + honest split + beat full-budget direct`

is too conservative for these high-accuracy, finite-budget settings.

The branch therefore should **not** promote the simple split certificate as the final method.

`PROBE_U10_NONORACLE_TRIGGER.m` was added so this diagnostic can be reproduced locally in MATLAB; the branch record does not claim that script has been executed in the current environment.

## Research interpretation

The first pass has produced both a positive theorem and a useful falsification:

1. unrestricted same-audit adaptation cannot be protected by a magnitude cap alone;
2. independence restores certifiability in principle;
3. paying for independence by a naive audit split can destroy practical certifiability.

That three-way tension is scientifically more interesting than the original safe-cap idea.

The emerging object is therefore a **safety–information boundary**:

> safe adaptive reuse requires control of dependence, but the information spent creating that control can itself eliminate the gain that safety is intended to preserve.

## Next target

Do not add more datasets. The next theory task is one of the following:

### Route A — dependence-controlled reuse without a fixed split tax

Seek a cross-fitted, orthogonalized, predictable, or otherwise dependence-controlled construction that uses most/all current outcomes while admitting a finite-sample risk bound.

Success criterion: a non-oracle certificate that is non-vacuous over a meaningful region and is not merely asymptotic.

### Route B — sharpen the impossibility boundary

If Route A fails, prove that no method in a broad same-audit class can simultaneously have nontrivial adaptive borrowing, uniform finite-sample MSE no-harm, and full-budget current-data efficiency without additional structural assumptions.

That would convert the negative finding into a principled impossibility theorem rather than an implementation failure.
