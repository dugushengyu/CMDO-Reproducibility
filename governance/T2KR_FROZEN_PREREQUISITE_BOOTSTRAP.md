# T2-KR frozen-prerequisite portable bootstrap

The Windows archival continuation passed T2-J and reached T2-KR after the LF-byte
adapter fix, then stopped before scientific computation because seven immutable
historical derived/frozen prerequisites present in the Drive authority had not been
materialized into the clean reviewer project root.

`CMDO-Archival-T2KR-Frozen-Prerequisites-v0.1.zip` contains exactly those seven
small files: the Stage11E-R source-recoverability decisions CSV, three Stage 8
dermoscopy frozen source axes, and three Stage11E-R breast-ultrasound frozen source
axes. Every member is byte-verified against the SHA-256 commitment already hard-coded
in the authoritative T2-KR v0.4 pipeline.

The archive contains no HiSBreast raw provider data. The approximately 1 GB
`HiSBreast_Version 2.zip` remains an external official-provider prerequisite and is
not redistributed in the reviewer portable package.

This change repairs reviewer packaging only. It does not mutate authoritative source
bytes, alter any frozen source axis, threshold, estimator, model, split, outcome,
scientific gate or claim, and it does not convert archival continuation into fresh
raw-to-science reproduction.
